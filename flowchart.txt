13. LOCAL HUB RULE

A Local Hub is a controlled logistics location.

Farmer Nearby path:
FARMER -> NEARBY -> DELIVERY PARTNER

NOT:
FARMER -> NEARBY -> HUB -> DELIVERY PARTNER

Warehouse long-distance path:
WAREHOUSE -> TOO FAR / HIGH RISK -> APPROVED LOCAL HUB -> DELIVERY PARTNER

A hub must be:
- approved
- active
- capacity available
- location configured
- supported product configured
- cold-storage capability checked when required

24. TRACEABILITY + RATING RULES

Traceability:
Farmer -> Harvest -> Batch -> Product -> Order -> Warehouse/Local Hub -> Delivery Assignment -> Customer -> POD

Every order item preserves farmerId, productId and batchId when available.

Perishability:
expectedShelfLifeHours + harvestedAt/harvestDate -> remainingShelfLifeHours -> travel time -> perishabilityRisk.

Ratings are separated:
- Product/Farmer: quality, freshness, quantity accuracy, description and batch quality.
- Warehouse/Hub: handling, packaging, storage and fulfillment accuracy.
- Delivery: on-time performance, handling, communication and delivery experience.

A delivery delay, traffic problem, warehouse delay or hub transfer does not automatically reduce a farmer's product-quality rating.
