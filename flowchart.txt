AGRICCONNECT AUTHORITATIVE MARKETPLACE WORKFLOW — 2026-09-30

FARMER
  1. Create / Manage Farm
  2. Create / Manage Crop
  3. Choose Product Creation Path
     A. Planned Harvest:
        Harvest Planning -> Mark as Harvested -> Create Batch/Lot
     B. Direct Product:
        Create Product -> system creates Batch/Lot
  4. Both paths -> Farmer declares grade -> Authorized verifier verifies quality
  5. Optional AI quality screening supports the inspection; AI does not replace the authorized verifier.
  6. Approved -> Product Active -> Marketplace
     Rejected -> Hold / Correction -> Re-submit

CUSTOMER
  7. Browse Marketplace -> View Product -> Quantity -> Cart
  8. Select Delivery Address
  9. Select Home Delivery
  10. Coupon (optional) -> Checkout -> Payment -> Place Order
  11. Delivery charge is calculated from the delivery address and shown before the final payment/order action.
  12. Customer never selects Farmer / Delivery Partner / Warehouse fulfillment.

FARMER ORDER FULFILLMENT
  13. Farmer receives order
  14. Confirmed -> Processing
  15. After Processing, choose exactly one fulfillment route:
      A. Farmer Fulfillment:
         Pack -> Dispatch -> Automatically open Farmer Order Map
         Self Delivery method: choose exactly ONE
           Route:
             Start Location -> Destination / Route -> Select Orders Along Route
           OR
           Radius:
             Select 2 / 5 / 10 / 20 / 50 KM -> Select Orders Within Radius
         Create ONE Self-Delivery Route
           Selected Orders -> Farmer Self Delivery -> Customer
           Remaining Dispatched Orders -> Automatically enter Delivery Partner Routing
             Nearby -> Local Hub -> Delivery Partner -> Customer
             Long Distance -> Warehouse -> Local Hub -> Delivery Partner -> Customer

      B. Warehouse Fulfillment:
         Farmer confirms bulk harvested product is ready at the farm
         -> Warehouse Collection Queue -> Collection Team Assigned
         -> Team En Route -> Arrived at Farm -> Verify Product/Quantity
         -> Collected -> Departed Farm -> Arrived Warehouse
         -> Warehouse Receive -> Quality Check -> Store
         -> Allocate warehouse stock to each individual order
         -> Order-level Packing Queue -> Packing Team -> Pack Each Order
         -> Verify Packing -> Ready for Dispatch
         -> Delivery Decision
         Nearby -> Warehouse Dispatch -> Delivery Partner -> Customer
         Long Distance -> Warehouse Dispatch -> Local Hub -> Delivery Partner -> Customer

      C. Farmer Fulfillment + Long Distance:
         Farmer packs each customer order -> Dispatch -> Delivery Decision: Long Distance
         -> Warehouse Collection Queue (already-packed transfer)
         -> Collection Team Assigned -> En Route -> Arrived at Farm
         -> Collect Packages -> Depart Farm -> Arrive Warehouse
         -> Warehouse Receive -> Quality Check -> Local Hub Transfer
         -> Local Hub -> Delivery Partner -> Customer
         Warehouse does NOT repack these farmer-packed orders.

         Farmer visibility:
         Warehouse Fulfillment mirrors: Fulfillment Selected -> Product Ready /
         Pickup Requested -> Collection Team Assigned -> En Route -> Arrived at Farm
         -> Collected -> Departed Farm -> Warehouse Received -> Quality Checked
         -> Stored -> Ready for Packing -> Packing Team Assigned -> Packing
         -> Packed -> Ready for Dispatch -> Delivery Decision -> Dispatched.
         For Farmer Fulfillment + Long Distance, the farmer sees the same
         collection/transfer milestones after dispatch; warehouse packing is skipped.

      Collection Queue rules:
         - It is the single warehouse bridge for farm-to-warehouse pickup.
         - bulk_harvest = warehouse fulfillment; warehouse packs later per order.
         - packed_orders_transfer = farmer fulfillment long-distance; never repack.
         - Collection Team status sequence: Ready -> Assigned -> En Route
           -> Arrived at Farm -> Collected -> Departed -> Arrived Warehouse.
         - Arrived Warehouse does not bypass Receive + Quality Check + Store.

  16. Each order/package keeps farmer, product, batch, order, warehouse,
      packing team, package and quantity traceability.

DELIVERY
  17. Delivery Partner accepts the job only from the selected pickup location.
  18. Pickup -> In Transit -> Customer Delivery -> Proof of Delivery
  19. Order Delivered -> Order Completed -> Review / Rating

GLOBAL RULES
  - Harvest Planning is optional.
  - Direct Product Creation is allowed.
  - Every marketplace product must have a traceable batch/lot.
  - Every marketplace product must pass authorized quality verification.
  - AI quality screening is assistive; authorized verification remains authoritative.
  - Customer checkout does not expose internal fulfillment choices.
  - Farmer fulfillment choice has exactly two options: Farmer Fulfillment or Warehouse Fulfillment.
  - Delivery Partner is a downstream transport role, not a third farmer fulfillment option.
  - Farm Pickup is removed from the new marketplace workflow; new orders are home delivery.
  - Delivery Partner never packs.
  - Warehouse packs only warehouse-fulfilled orders.
  - Proof of delivery uses delivery evidence; OTP is not required by this workflow.

The sections below contain the project's broader/historical implementation documentation.
Where older sections mention farm pickup or customer-selected fulfillment, the authoritative workflow above takes precedence.
